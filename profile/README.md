<p>第一步不是动手，而是想清楚要什么。你的调用是离散短请求还是长连接、并发高不高、是否怕地区跳动。需求不清，后面选什么、怎么配都没有依据。花几分钟想清楚，比返工省时间得多。</p>

<p>第二步是准备出口信息：确认你要用的资源属于什么归属、落在哪个地区、是否固定。这些信息是配置时要填的依据，也是日后核对的基准。把信息提前写好，配置时就不容易填错。</p>

<p>第三步是配置。一般就是把请求指向你选定的出口，并填好必要的连接信息。不同环境的界面和字段不同，这里不给具体点击顺序，因为那会因为环境而异、很快过时。抓住一个原则：你在让请求经由谁转发，别填错对象就好。</p>
